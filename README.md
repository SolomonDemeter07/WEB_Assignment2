# Assignment 2: Advanced CSS (Flexbox & Grid)

**Student:** Bekeshev Askhat 
**Group:** SE2524

## Objective
This project demonstrates the application of advanced CSS layout techniques using Flexbox and CSS Grid. The goal is to build complex, responsive layouts without relying on floats or external frameworks.

## Project Structure
* **Task 0 & 1 (Flexbox):** Navigation bar and card row utilizing Flexbox for horizontal alignment, equal-height distribution, and spacing.
* **Task 2 (Grid System):** Page layout structure (Header, Sidebar, Main Content, Footer) implemented with CSS Grid Areas.
* **Task 3 (Image Gallery):** Image gallery grid with equal-width columns and rows, including hover caption effects.
* **Task 4 (Combining Flexbox & Grid):** Portfolio page using CSS Grid for the main macro-layout (Projects and Sidebar) and Flexbox for micro-components inside the project cards.
